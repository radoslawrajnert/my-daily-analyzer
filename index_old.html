Settings

    
Optional: add a free Spoonacular API key to pull real recipes with real photos and live nutrition data into "Propose a meal" instead of the built-in list. Your key is stored only in this browser — it's never sent anywhere except directly to Spoonacular. No key needed to use the built-in 200-recipe list.

    


    
Backup & Restore

    
Save a complete copy of your data (including photos) as a file on your computer, or restore from one. Useful for moving your data into a fresh copy of this app (like right after publishing it online) — export here first, then import it there.

    

      
      
      
    


    
Cloud Sync (optional)

    
Use this app on more than one device (like your phone) with the same data. Requires a free Firebase project — see the setup guide for step-by-step instructions. Paste your project's config below to turn it on; leave it empty to keep everything local-only, exactly as before. Progress photos and package photos stay on this device only and are never uploaded.
